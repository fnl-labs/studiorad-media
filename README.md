# studiorad-media

Coda delle pubblicazioni programmate di Studio Radiologico (Instagram + Pagina Facebook).
Un `.json` in `coda/` esce da solo alla sua ora (vedi `coda/LEGGIMI.md`); il workflow
`pubblica.yml` gira ogni 10 minuti e archivia in `pubblicati/` con i link.
Secret della repo: `META_PAGE_TOKEN`, `META_PAGE_ID`, `META_IG_USER_ID`.
